# Sade Sati

**Status:** planned

## Purpose

Explain whether the native is in Saturn’s Sade Sati (or related Shani Dhaiya), where they are in the cycle, and when the phase ends — grounded in transit/Saturn doctrine, not guesswork.

## User need

Users hear they are “under Sade Sati” and want to know if that is true now, what life themes to expect, and when relief is traditionally indicated.

## Inputs the user provides

- Birth details (Moon sign context is essential for Sade Sati)
- A question about Sade Sati, Shani Sade Sati, or Shani Dhaiya, including “am I in it” / “when does it end”

## What the answer must contain

- Clear status: not started / in progress (which phase if the doctrine distinguishes) / completed, relative to “today”
- Start and end framing for the current or upcoming Sade Sati span when calculable
- Life-theme guidance tied to Saturn’s transit relative to the Moon, in plain language
- Distinction between Sade Sati and generic Saturn dasha hardship when both could be confused
- Grounded caution language — no fatalistic predictions of catastrophe

## Grounding source

**Phaladeepika** (Mantreswara) and related transit / Sade Sati doctrine planned for corpus expansion; BPHS alone is not treated as sufficient grounding for shipping this as a confident product.

## Out-of-scope

- Using Sade Sati as a catch-all explanation for every difficulty
- Kaal Sarp or Pitru Dosha bundled into the same answer unless the user asked
- Western Saturn-return equivalence presented as Vedic Sade Sati
- Exact event dating (“job loss on date X”) from transit alone

## Success signal

Sade Sati golden questions retrieve transit-grounded passages, the answer’s in/out/end claims match the computed Saturn–Moon geometry for the case, and dosha-tagged quality gates pass after Phaladeepika (or equivalent) ingest.
