# Timing windows

**Status:** live

## Purpose

Answer questions about *when* — next N days/months/years, this year, coming week — using resolved date windows and Vimshottari dasha transitions, not vague “soon” language.

## User need

Users want to know what is active now, what ends soon, and whether a major period change falls inside the horizon they asked about.

## Inputs the user provides

- Birth details sufficient to cast a chart
- A question that implies a time horizon (e.g. “next 6 months”, “coming week”, “this year”) or an explicit window

## What the answer must contain

- The asked window restated in calendar terms (start and end relative to “today”)
- The active mahadasha and antardasha with end dates where known
- Days until the active antardasha (and mahadasha, when relevant) ends
- Whether any dasha transition falls inside the window; if none, say so explicitly
- When the horizon is longer than a short near-term checkpoint, a brief near-term (≈6-day) checkpoint so the user is not left only with a distant end date
- Plain-language translation of period lords into life themes relevant to the user’s question domain

## Grounding source

**Bṛhat Parāśara Horā Śāstra (BPHS)** Vimshottari dasha doctrine for period lords and sequencing; timing answers must not invent transit rules that the current corpus does not support.

## Out-of-scope

- Precise clock-time event prediction (“you will get the offer on Tuesday at 3pm”)
- Western progressions, solar returns, or non-Vimshottari systems as primary timing
- Sade Sati / transit-Saturn narratives as a substitute for dasha windows (see planned Sade Sati spec)
- Muhurta electional charts for wedding/travel dates as a dedicated product

## Success signal

For a horizon-framed question, the answer states the window, active periods, countdown-to-change facts, and transition presence/absence without contradicting the computed timing report.
