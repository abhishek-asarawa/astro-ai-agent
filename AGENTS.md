# Agent instructions

This repo’s coding standards and feature specs live under `docs/`. Agents should
treat those docs as the source of truth—not this file.

## Where to look

- **Standards index:** [docs/standards/README.md](docs/standards/README.md)
- **Feature specs index:** [docs/specs/README.md](docs/specs/README.md)

## Workflow

1. Before writing or changing code, open the standards index and follow the
   relevant docs under `docs/standards/`.
2. Before building or changing a feature, open the specs index and read
   `docs/specs/<feature>.md`.
3. When exploring project context (including brainstorming), include
   `docs/specs/README.md` so design work stays aligned with existing specs.

Cursor-specific rule maps live under `.cursor/rules/` (`astro-standards.mdc` and
glob-scoped companions). This `AGENTS.md` is the portable pointer for any agent.
